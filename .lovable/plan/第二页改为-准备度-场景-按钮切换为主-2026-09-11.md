# 第二页改为「准备度」场景（按钮切换为主）

用一个整屏场景替换现在四个手机框的那一页。低准备度和高准备度共用同一套版面和同一批元素，切换时不重建、不跳页。本次只改第二个场景，第一页和其他段落保持不变。

## 交互：按钮优先

- 顶部一个两段切换控件：`Low readiness` / `High readiness`，这是主要交互，方便录 demo 时定格
- 点击后停留在该状态；一次切换约 1.2 秒；连续点击时从当前进度平滑反向，不重置重播
- 分两阶段实现：
  - 第一阶段只实现按钮切换
  - 第二阶段进入场景时自动播放一次；用户一旦点过按钮就立即接管，离开场景再回来才恢复自动演示资格
- 不做滚动位置连续驱动，不做长距离滚动吸附
- 减少动态效果时直接切换，不播放动画

## 一个统一的 progress

整段只有一个 `progress: 0 → 1` 状态，同时驱动分数、指标条、角色透明度、建议文字和周计划位移，保证所有内容同一时刻完成切换，不会出现「数字变了但建议还没变」。

所有由 progress 控制的视觉属性直接做数值插值（写在样式里，由动画帧计算），不叠加 CSS transition，避免两个动画来源打架。

## 画面结构（两种状态共用）

左：牛油果角色 + 准备度分数
- 一个固定比例插画位，两张图交叉淡化。两张图必须同画布尺寸、同角色大小、同脚底基准线，否则会重影跳位
- 大号分数 `38` ↔ `86`，数值连续插值，下面一行状态标签
- 角色只在两种姿态之间过渡；想要「低头逐渐抬头、表情变开心」这种连续动作，需要分层 SVG，两张 PNG 做不到

中：Apple Watch 指标，四行 + 发丝分割线 + 数值条，每行同时标出个人基线
- 睡眠时长 5h12m ↔ 7h48m（基线 7h30m）
- 深睡比例 9% ↔ 22%（基线 20%）
- 静息心率 68 ↔ 54 bpm（基线 55）
- HRV 31 ↔ 62 ms（基线 60）

右：建议区，两块，固定高度，切换不引起布局跳动
- 每块先一句结论 + 2–3 条要点；详细内容在独立面板里打开，不改变主场景布局

角落一行小字标注「示例状态 / Sample data」，避免看起来像正在实时测量。

## 建议内容

低准备度
- 饮食结论：先稳住血糖和补水，晚上帮助入睡。要点：燕麦 + 香蕉；水 + 电解质；酸奶坚果补镁；咖啡因限 1 杯且中午前
- 训练结论：今天不练力量。要点：20–30 分钟低强度有氧或活动度，心率 ≤ 最大心率 60%
- 周计划：背部日顺延一天，休息日提前到今天，本周 4 次训练量不变

高准备度
- 饮食结论：为今天的训练加满油。要点：练前 2 小时 40g 碳水；每公斤体重 1.8–2.2g 蛋白；练后 30 分钟 30g 蛋白 + 快碳
- 训练结论：按计划做背部日。要点：主项加 2.5–5% 负荷，5×5，约 55 分钟
- 周计划：不变

## 周计划的表达

周一到周日七个格子位置固定，移动的是格子里的任务块。「背部训练」和「休息」两个任务元素在格子之间平移交换，让人一眼看出是自动重排，而不是两个格子换了文字。

## 视觉规则

沿用现有风格：奶油纸背景、发丝分割线、平面区块、等宽小写标签和数字；不加圆角卡片和胶囊标签。低状态偏灰调，高状态用牛油果绿点缀。移动端改为纵向堆叠，不强塞一屏。

## 技术说明

- 新增 `src/components/concept/ReadinessScene.tsx`，配套子组件：指标行、建议块、周计划条、建议详情面板；数据常量集中在一个文件里
- `src/routes/index.tsx` 用它替换 `ScreenGallery`；删除 `ScreenGallery.tsx`，`PhoneFrame.tsx` 保留给 Spotlight
- 不引入动画库：progress 用 React state + `requestAnimationFrame` 缓动，视觉插值走内联 style
- 角色图先用占位框，之后替换为 `src/assets/*.asset.json`
- 背景沿用现有 1920×1200 图，与上下页对齐
